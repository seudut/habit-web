# 习惯打卡 Web App

一个按月记录每日习惯的最小可用版本：

- 月度习惯矩阵：分类、分项、目标、日期四段结构
- 支持时间点、分钟、次数和勾选录入
- 每日总体得分面积图
- 睡觉、实修、阅读三张独立的分项每日得分折线图
- 睡觉图表纵轴显示偏离目标的时长，并使用虚线标出 0 目标线
- 矩阵只读展示；早睡、早起可直接在矩阵中编辑时间点
- 周末日期使用独立颜色区分
- 矩阵自适应主内容区宽度，宽屏可一次显示完整的 31 天
- 今日快捷打卡
- 月度总览、连续达标天数
- 电脑和手机响应式页面
- SQLite 本地持久化

## 本地运行

```bash
npm install
npm run build
npm start
```

然后访问：

- 本机：http://localhost:3000
- 同一局域网内的手机：http://192.168.31.56:3000

首次启动会自动创建示例习惯：

- 睡觉：早睡 22:30、早起 06:30，记录时间点
- 实修：站桩 30 分钟、打坐 20 分钟
- 阅读：文史 30 分钟、哲思 30 分钟

并生成当前月份的演示数据。页面可以直接修改，也可以点击右上角“清空本月”。

归一化规则：

- 时长类习惯按实际值 ÷ 目标值换算为 0–100 分
- 时间类习惯在目标时间之前记为 100 分，晚于目标后按容忍范围递减
- 未记录当天显示 0，有记录时按 1–100 计分

数据库文件保存在：

```text
data/habits.db
```

## 开发模式

```bash
npm run dev
```

部分 macOS 环境下的文件监听器可能出现 `EMFILE` 警告；如果遇到，直接使用 `npm run build && npm start` 即可，不影响使用生产模式。

## Docker / VPS

```bash
docker compose up -d --build
```

应用监听 `3000` 端口，SQLite 数据保存在 Docker volume `habit-data` 中。

## 目录结构

```text
app/
  api/          月数据、习惯、打卡记录接口
  page.tsx      月视图入口
components/     页面、表格和图表组件
lib/
  db.ts         SQLite 初始化和写入
  data.ts       月度统计汇总
  types.ts      共享类型
```
